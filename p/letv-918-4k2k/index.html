X50Air 2D、X50Air 3D官改精简刷机固件（蓝同学版），去除广告和安装限制

本文适用于乐视电视918芯片4K2K版本，具体型号为：X50Air 2D全配、X50Air 2D C罗足球、X50Air AUO、X50Air 2D芈月版、X50Air 3D全配、X50Air 3D C罗足球等。

准备工作#

刷机有风险，操作需谨慎！

  • 一个U盘（usb2.0、FAT32、16G及以下、不能是PE系统盘）

  • 一台电脑

  • 下载好刷机需要的固件

刷机或者升级电视时，请开启UART，避免电视损坏无法救砖。（开启UART方法在工程模式-other-uart enable使其处于on。）

如果你刷官方包，或者第三方ROOT包出现指示灯亮电视不开机，UART已经开启。不用怕，还有救。串口刷机。

刷机文件说明#

先刷原厂包，再精简版！

  • 原厂包 LetvUpgrade_4K2K6.0.072N_0801

  • 精简包 LetvUpgrade_4K2K-beta

刷机操作#

  1. 下载好固件，刷机文件“ LetvUpgrade_4K2K.bin”一定要拷贝到U盘的“根目录”下，不可以放到其他文件夹内，否则无法识别刷机包；

  2. 顺序：先刷原厂包，再精简包

  3. U盘插顶部的隐藏USB接口，如果不行，再换其他接口；

  4. 刷完原厂固件，进入设置向导的时候请直接关机，不要有其他操作，否则接下来会导致你刷固件失败！

  5. 刷完精简的固件之后，系统会自动待机，按遥控器电源开机即可进入系统；

电视上操作步骤#

  1. 将U盘插入超级电视USB2.0接口

  2. 电视机身有没有实体按键

    • 若电视背板有实体按键，在超级电视关机状态下按住电视背板的【确定】键不松手，同时打开电视总电源翘板或按键开关，待出现升级进度条后，可松开【确定】键。并进行第4步；

    • 若电视机身无实体按键，则直接打开电视总电源翘板或按键开关，超级电视进入待机状态，且指示灯微亮，并进行第3步；

  3. 你的遥控器是哪种

    • 若您电视遥控器是39键遥控器，依次按下【3】、【6】、【9】、【5】、【开机】键，稍等片刻，电视会出现系统升级进度条；

    • 若是您使用超级遥控器3，依次按下【设置】【音量加】【音量减】【频道减】【频道加】【开机】键，稍等片刻，电视会出现系统升级进度条；

  4. 待进度条走完会自动进入系统，首次开机启动时间会比较长，请您多耐心等待一段时间，待进入系统后表示升级完毕。

    此操作过程不要断电，不要移除U盘！

备注：强制升级会清除电视内所有数据，例如：本地照片、视频、安装的应用、账号信息等，请注意数据备份，单机游戏存档无法恢复，非乐视应用商店、游戏大厅下载的APP无法恢复；

精简刷机包特色#

  • 去除了乐视的开机广告
  • 去除乐视桌面推送的广告
  • 去除乐视的不实用桌面插件
  • 只保留信号源、应用
  • 应用桌面置顶的10个应用修改为旧版本5个应用
  • 5个应用分别为云视听电视猫、星火直播、银河奇异果、文件管理、浏览器
  • 去除了广电对应用安装的管控
  • 去除了后台升级应用，开机下载广告、系统升级

进阶玩家：修改应用图标以及背景图#

  • 如何修改应用界面，应用界面位置为”/system/plugin/com.stv.plugin.app.apk”，可以使用别人制作好的应用插件替换内置的插件。
  • 应用桌面的五个固定应用是根据需要自己安装的，如果你不喜欢可以不安装，它只是一个图标。如果动手能力强的可以解包自行修改替换图标和对应的快捷方式，甚至更换背景图片。
