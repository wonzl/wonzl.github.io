在Hugo博客网页中嵌入Bilibili视频 不跳转B站

在Hugo博客网页中嵌入Bilibili视频，通过shortcode来实现是最好的方法；最烦人的就是点击播放器就跳转到B站去了。本文的方法不弹窗、不跳转到B站，就在我自己站内播放。但是也有限制，就是不能设置清晰度，不能调整倍速。

先看嵌入B站视频的效果#

1、新建 shortcode#

PaperMod主题路径：layouts/_shortcodes/bilibili.html

<div style="position: relative; padding-bottom: 56.25%; width: 100%; height: 0;">
  <iframe 
    src="//player.bilibili.com/player.html?bvid={{.Get 0 }}&page={{ if .Get 1 }}{{.Get 1 }}{{ else }}1{{ end }}&danmaku=0&autoplay=0" 
    scrolling="no" 
    border="0" 
    frameborder="no" 
    framespacing="0" 
    allowfullscreen="true" 
    sandbox="allow-same-origin allow-scripts"
    style="position: absolute; top:0; left:0; height: 100%; width: 100%;">
  </iframe>
</div>

参数说明：#

  • autoplay=0 关闭自动播放，改成 1 开启自动播放；
  • danmaku=0 默认关闭弹幕，改成 1 开启弹幕；// 好像无效？
  • sandbox 限制：禁止点击播放器跳转到 B 站，不会弹出 B 站页面；
  • padding-bottom:56.25% 控制视频比例为16:9，如果要4:3就改成75%，视频宽度根据页面自适应；
  • 协议为相对协议 //，自动适配 http / https ；
  • 网传的参数 high_quality=1 可以指定最高清晰度，经过测试无效，所以去掉了。

2、Markdown 调用方式#

1

{{< bilibili BVxxxxxx >}}

针对多集视频，比如指定第2集：

1

{{< bilibili BVxxxxxx 2 >}}

已知限制：#

  • B 站官方外链播放器无法设置清晰度，不能调整倍速；

  • 仅支持 BV 号，不支持 AV 号；如果有需要可以用下面的代码。

可选：支持AV的版本#

{{ if hasPrefix (.Get 0) "BV" }}
{{ $vid := .Get 0 }}
<iframe src="//player.bilibili.com/player.html?bvid={{ $vid }}&page={{ if .Get 1 }}{{ .Get 1 }}{{ else }}1{{ end }}&danmaku=0&autoplay=0" scrolling="no" frameborder="0" allowfullscreen allow="fullscreen" sandbox="allow-same-origin allow-scripts" loading="lazy" style="position:absolute;top:0;left:0;width:100%;height:100%"></iframe>
{{ else }}
{{ $aid := .Get 0 }}
<iframe src="//player.bilibili.com/player.html?aid={{ $aid }}&page={{ if .Get 1 }}{{ .Get 1 }}{{ else }}1{{ end }}&danmaku=0&autoplay=0" scrolling="no" frameborder="0" allowfullscreen allow="fullscreen" sandbox="allow-same-origin allow-scripts" loading="lazy" style="position:absolute;top:0;left:0;width:100%;height:100%"></iframe>
{{ end }}

以上就是在Hugo博客网页中嵌入Bilibili视频 不弹窗不跳转的方法，其实最关键的参数就是 sandbox="allow-same-origin allow-scripts" 。

如果想要嵌入其他网站的视频（腾讯/爱奇艺/优酷）也可以照葫芦画瓢，再新建一个shortcode ，然后修改src里的内容就可以了。
