超4电视938芯片系列官改刷机固件（蓝同学），去除广告，安装限制。

本刷机包适用于乐视电视以下型号#

本文适用于乐视超4电视938芯片系列，具体型号有：超4 X50、超4 X50 PRO、超4 X40、超4 X40 中超版、超4 X43、超4 X43 中超版、超4 X55 CSOT（32G)、超4 X55 AUO（32G)、超4 X55 LGD（32G)、超4 X55 Curved、超4 X55 Curved、超4 X65 Curved等。

电视的系统版本#

系统版本必须是EUI6.5、系统版本是EUI6.5、系统版本是EUI6.5。

不是的请自己下载6.5的包，升级或者降级。

准备工作#

刷机有风险，操作需谨慎！

  • 一个U盘（usb2.0、FAT32、16G及以下、不能是PE系统盘）
  • 一台电脑
  • 下载好刷机需要的固件

刷机文件说明#

下载完成解压 938_65.072s_0715_beta.7z ，将解压后的四个文件全部放入U盘根目录。

  1. LetvUpgrade938.bin 是电视的强刷包。文件名固定，该文件是单recovery分区的强刷包。

  2. UPDATE-Recovery-After-Install 是刷入recovery后需要马上刷入的包，可以对系统恢复recovery进行处理。

  3. 938_65.072s_0715_beta.zip 是制作好的卡刷包，系统精简处理版本号是eui6.5。

  4. UPDATE-SuperSU-v2.82** 是supersu的卡刷包，用以获取root权限

刷机步骤#

再次确认你的电视目前的系统版本必须是EUI6.5，将电视恢复出厂设置后再继续。

一. 刷入recovery#

A、B方案任选，A不行的可以试试B。注意在用A、B方案刷入recovery后，电视不能开机进系统、否则重新刷入。

  • A：电视设备待机下，设置、音量加、音量减、频道减、频道加、电源键。稍等几秒，电视进度条一闪而过，设备重新待机。此时recovery已经刷好。

  • B：电视设备断电下，按设备机身确定键保持不动，设备通电。稍等几秒，电视进度条一闪而过，设备重新待机。此时recovery已经刷好。

二. 电视进入recovery界面#

A、B方案任选，A不行的可以试试B。

  • A：电视设备待机下，设置、音量加、音量减、频道加、频道减、电源键。稍等几秒，电视进入recovery。

  • B：电视设备断电下，按设备机身音量加保持不动，设备通电。稍等几秒，电视进入recovery。

三. 在recovery界面刷入系统包#

  1. 将光标移动到wipe data/factory reset，选中确定，接着选yes（恢复出厂设置）

  2. 将光标移动到wipe cache partition，选中确定，接着选yes（清除缓存）

  3. 将光标移动到apply update from external storage，选中确定，然后会出现U盘列表（一般情况下是no name）

  4. 选中你的U盘，确定进入你的U盘的文件列表。依次序选中UPDATE-Recovery-After-Install 、938N_65.072N_0715_beta.zip 、UPDATE-SuperSU-v2.82**刷入。

    举例：选中UPDATE-Recovery-After-Install确定，选yes，开始刷入。刷入完成后会重新弹出菜单，此时重复步骤3/4。

  5. 三个文件刷完后。在弹出的菜单处选择，reboot system now。电视重新待机，遥控开机即可。

解决办法：重新刷入recovery
